# Delivery status and remaining work

Implemented: Next.js responsive dashboard/light-dark theme, register/login/logout with hashed opaque sessions, encrypted nullable profiles and configurable score weights, versioned PDF/DOCX resume uploads with review/confirmation and ownership checks, PostgreSQL migrations, conservative deterministic eligibility/evidence decisions, Greenhouse/Lever public-feed ingestion, exact quote/span/hash storage, source freshness, deduplication by canonical original URL, successful-feed closure detection, asynchronous scheduled refresh, embedding-based fit, source-backed extractive catalogue search, saving/hiding/comparison, application Kanban/table and notes/reminders/resume selection, in-app alerts and opt-in SMTP daily/weekly digests, private data export/account deletion, rate limits and CSRF Origin checks.

Not implemented or not production validated:

- Live provider extraction/embeddings, real resumes, actual employer feeds and SMTP delivery need network/credentials and provider-backed evaluation. Unit tests do not establish real-world model accuracy. Exact quote validation proves a quote exists, not that a model correctly interpreted it or found every condition. Eligibility depends on extraction completeness; public verified claims require independent extraction evaluation and a review/quality-control process.
- Workday, Ashby, SmartRecruiters, government, university pages, authorized search APIs, autonomous new-company discovery, AI query generation and full conversational reasoning. Current source configuration is operator-managed; dynamic query suggestions are deterministic and not executed. No login/CAPTCHA bypass or arbitrary URL fetcher exists.
- Inferred standing progression is deliberately unsupported: confirm standing at internship start with a target date. Complex experience and unsupported requirement semantics remain UNKNOWN. Exact major/citizenship differences remain UNKNOWN because aliases can differ. Closed/incomplete/stale sources are Unverified.
- Resume-specific job advice and truthful tailored improvement generation. Matching uses the confirmed profile; original resume versions remain available for application tracking.
- Indexed full-text/embedding retrieval at catalogue scale, full salary/date/degree/graduation filters, normalized compensation comparison, feed pagination for future providers, and canonical cross-provider deduplication beyond exact original URLs. Current authenticated search scans at most 1,000 indexed SQL-filtered candidates and reports truncation. Saved counts and views are bounded to the current retrieved page.
- Email ownership verification, password reset, MFA, abuse controls for email, breach detection, security audit, managed auth, RLS defense-in-depth, isolated upload parsing/malware scanning, key rotation, error monitoring, exhaustive data exports, full backup deletion policies, and load testing. Do not expose registration/email delivery to the public before addressing account recovery/verification and upload isolation.
- Redis scheduler is a single elected polling worker, not a durable per-job task queue; lease renewal, failed-job replay, dead-letter queues, transactional email outbox and exactly-once external email are outstanding. Posting update alerts currently signal source versions and can include an initial version for saved jobs. Notification categories have only shared in-app/email preferences, plus preferred-company selections.
- Automated browser accessibility/responsive/end-to-end tests, real provider red-team/evidence datasets, hosted deployment, deployment smoke tests and production monitoring remain outstanding unless separately recorded in VALIDATION.md.

No generated sample jobs are shown to users. Controlled employer fixtures are confined to automated tests. No primary student profile is preloaded, and no degree/GPA/citizenship/authorization/certifications are inferred.
